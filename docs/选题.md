
# Lecture-Link：基于边缘多模态融合的实时课堂知识蒸馏器

## 项目名称
中文名： Lecture-Link：基于边缘多模态融合的实时课堂知识蒸馏器 
英文名： Lecture-Link: An Edge-AI Real-Time Knowledge Distiller for Classrooms

## 一、 核心设计理念 (The Concept)
产品定位： 针对学生场景，利用 Intel 边缘侧算力做“实时处理 + 本地整合 + 学习专用优化”。它不仅是一个课堂记录仪，更是一个学生的“外挂式海马体”。它不像录音笔那样只负责“听”，它像一个学霸同桌一样负责“听懂、记重点、划范围”。

核心特点：

完全离线实时性： 课堂上不需要联网，字幕和提纲实时在屏幕（连接的触摸屏）上滚动。

多模态对齐： 将老师讲授的内容和学生拍照上传的重点自动对齐，形成“图文音”合一的笔记，将多模态信息融合到知识图谱中。

分级处理架构： 边缘侧做“快思考”（实时速记、抓重点），云端做“慢思考”（深度总结、复习出题）。

## 二、 系统功能架构 (What it does)
### 1. 实时听课与板书对齐 (Real-time Alignment)
音频处理： 边缘侧运行 Whisper (Distilled/Tiny版本)，实时将老师的语音转为文本。

多模态融合：

用户（学生）在听课时，如果老师翻到了复杂的PPT或在黑板写了公式，学生用手机/PC拍一张照传给设备。

关键点： 设备利用 OCR 提取图片内容，利用 NPU 分析图片语义，将其插入到当前的“语音流”中，生成一段“图文并茂”的原始记录。

### 2. 动态知识图谱构建 (Live Knowledge Graph)
功能： 不同于生成线性的文字，设备在后台利用 SLM（小语言模型）实时分析、提取关键词（Entities）和关系（Relations）。

展示： 在用户的屏幕上，实时生长出一棵“知识树”**。

例子： 老师讲到“傅里叶变换”，屏幕上出现中心节点；讲到“时域转频域”，延伸出一个子节点。

价值： 帮助学生在课堂上建立结构化思维，防止“听着听着就走神/跟丢了”。

### 3. 课后混合云增强 (Hybrid-Cloud Enhancement)
功能： 课后，设备将结构化的“原始笔记”同步给部署在本地的Agent。Agent调用更强大的云端模型（如DeepSeek-V3/GPT-4/Qwen3-Max），根据原始笔记生成完整的复习文档、记忆卡片、待办事项，甚至模拟出题。

## 三、关键技术实现

### 1. 硬件平台与交互配置

- **主控核心**：采用基于 Intel® Core™ Ultra 5 Processor 225U 的 DK-2500 开发套件。利用其集成的 NPU (Intel AI Boost) 处理低延迟实时任务，iGPU 辅助视觉计算。

- **存储与运行环境**：配备 16GB SO-DIMM DDR5 内存以支撑本地 Agent 并发运行，128GB SSD 用于存储本地知识图谱数据。

- **多模态感知外设**：
  - **音频**：通过 USB 3.2 接口连接高性能麦克风阵列，实现波束成形拾音。
  - **无线**：通过 M.2 E-Key 扩展 AX201 Wi-Fi 6 模组，实现学生手机照片的低延迟传输。
  - **交互显示**：通过 HDMI 2.1 接口外接一块 10.3 寸触摸屏。在 Ubuntu 22.04 环境下，利用原生触控支持，实现知识图谱的交互式缩放与查看。

### 2. 边缘侧 AI 引擎 (OpenVINO Stack)

- **ASR 语音转录**：使用 OpenVINO 加速的 Whisper-v3-Turbo。通过 Int8 量化部署在 NPU 上，实现课堂语音到文本的零延迟流式转化。

- **实时语义提取 (SLM)**：在本地运行 Phi-3-mini 或 Qwen-2.5-1.5B 模型。职责：实时从文本流中提取实体（Entities）和关系（Relations），动态更新内存中的 JSON 知识树。

- **轻量级 VLM 融合**：利用 Llava-Phi-3 理解学生上传的 PPT/板书照片，生成语义描述（Caption），并根据时间戳将其自动对齐至笔记流中。

### 3. 本地 Agent 系统与云端协同 (The Agent Core)

- **Agent 架构 (OpenClaw-like)**：在 Ubuntu 上部署基于 Python 的轻量级 Agent 框架，作为系统的“指挥中心”。

- **技能库 (Skill System)**：
  - **Summarizer Skill**：调用云端 DeepSeek-V3 API，将课堂原始记录扩写为结构化复习文档。
  - **Todo-Detective Skill**：识别老师口语中的任务指令（如“下周交作业”），自动生成待办事项并同步至用户日历。
  - **Quiz-Master Skill**：基于课堂生成的知识图谱，通过云端模型生成针对性的模拟试题与记忆卡片 (Anki)。

- **状态管理**：Agent 负责维护“听课上下文”，确保云端 API 调用时能携带最关键的本地提取信息，减少 Token 消耗并提升准确度。

### 4. 混合架构工作流 (Revised Workflow)

- **Step 1 (Edge Real-time)**：Audio/Image Stream -> NPU/iGPU (Whisper + VLM) -> SLM 提取结构化数据 -> 实时渲染至触摸屏“知识树”。

- **Step 2 (Local Agent Orchestration)**：课堂结束触发同步，本地 Agent 整合本地 Markdown 笔记、OCR 结果与知识节点。

- **Step 3 (Cloud Augmentation)**：Agent 根据用户需求调用 DeepSeek/GPT-4 接口，执行高级 Skill 任务，将结果反馈至本地存储并推送到学生手机端。
